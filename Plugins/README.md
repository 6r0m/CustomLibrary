# Plugins

Each folder here is one plugin, installable on its own.

| plugin | owns |
|---|---|
| [AnimationDataTools](AnimationDataTools/README.md) | animation curves and bone rotations from named channel data |
| [StreamingAudio](StreamingAudio/README.md) | playback of PCM and MP3 that arrive in pieces; WAV read, write and chunking |
| [TextProcessing](TextProcessing/README.md) | incremental text fragments and validated regex replacement |
| [UnrealUtilities](UnrealUtilities/README.md) | validated random, scene/physics and project utilities |
