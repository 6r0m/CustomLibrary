# UnrealUtilities module

Runtime module holding three focused Blueprint function libraries:
`URandomUtilitiesLibrary`, `USceneUtilitiesLibrary` and `UProjectUtilitiesLibrary`.

| concern | owner |
|---|---|
| what each utility validates, returns and relies on | [docs/README.md](docs/README.md) |

**Entry points:** `Public/RandomUtilitiesLibrary.h`, `Public/SceneUtilitiesLibrary.h` and
`Public/ProjectUtilitiesLibrary.h`. A runnable example is the
`UnrealUtilities.Example.WeightedTable` test in
[the module's tests](https://github.com/6r0m/CustomLibrary/blob/develop/Plugins/UnrealUtilities/Tests/Source/UnrealUtilitiesTests/Private/UnrealUtilitiesTests.cpp).
