# UnrealUtilitiesTests

Tests of the UnrealUtilities module. Case data is in `Private/Cases/HelperCases.h`.

| group | covers |
|---|---|
| `Random` | weighted selection: valid and refused inputs |
| `Scene`, `Project` | locked axis, collision-sphere view test, project version |
| `Guard` | engine calls that share a name with a retired helper stay allowed |
| `Blueprint` | the reflected surface and a compiled graph calling every library |
| `Example` | a reproducible weighted reward table |
